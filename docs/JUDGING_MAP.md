# 🏆 BLINDSPOT — ForgeHacks 2026 Judging Alignment Matrix

This document explicitly maps every core and unique module of **BLINDSPOT** to the five official hackathon judging criteria for the **AI + Education** track.

---

### 1. Innovation & Originality (25%)
| Module | What It Does | Why It Sets BLINDSPOT Apart |
|---|---|---|
| **Blindspot Calibration Engine** | Calculates $\text{Blindspot} = \text{Confidence} - \text{Score}$ and plots subjective probability vs empirical accuracy curves. | Most AI tools measure raw accuracy; BLINDSPOT measures the *metacognitive illusion of competence*. |
| **Misconception Fingerprinting** | Multi-dimensional radar telemetry mapping recurring systemic reasoning biases (e.g. Causal Inversion, Left-Prefix Violation). | First tool to build an ontological cognitive fingerprint across disparate CS topics. |
| **Confused Student Mode** | Inverted teaching arena leveraging the Protégé Effect where learners repair an AI's hidden misconception. | Reverses the standard student-AI dynamic: the student teaches and diagnoses rather than consumes. |

---

### 2. AI Depth & Technical Execution (25%)
| Feature | Implementation Mechanism | Technical Significance |
|---|---|---|
| **Dual-Agent Verifier Pipeline** | Secondary LLM agent audits every scenario for ambiguity, recall-reliance, and factual accuracy. | Guarantees transfer learning depth and eliminates rote keyword regurgitation. |
| **Bayesian Knowledge Tracing (BKT)** | 4-parameter probabilistic state updates ($P(L_0), P(T), P(S), P(G)$) with hint penalty deductions. | Real statistical cognitive modeling rather than arbitrary heuristic grading. |
| **Graph Relational Decay** | NetworkX DAG topology propagates uncertainty decay along prerequisite edges upon failure. | "Mastery on connections": repairs root foundation gaps when complex synthesis fails. |
| **Fault-Tolerant LLM Engine** | Auto JSON markdown sanitizer, 2-stage retry-and-repair loop, and zero-latency `DEMO_MODE` fallback. | Bulletproof production resilience preventing broken demo states. |
